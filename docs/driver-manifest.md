# Манифест драйвера (`driver.toml`)

Лежит в корне репозитория каждого драйвера организации [Redox-openDriver](https://github.com/Redox-openDriver). Из него
собирается страница драйвера в каталоге: название, описание, поиск и фильтры по меткам. Всё, что видит пользователь
сайта, берётся отсюда, а не из кода.

## Имена
- `family` — `<производитель><класс>` латиницей в нижнем регистре: `elanfp`, `elantp`, `mt7921wifi`. Так называются
  программы, крейты и служба драйвера.
- `id` — `<family>-<модель>`: `elanfp-0c4b`. Совпадает с именем репозитория. У драйвера, который поддерживает несколько
  моделей, модели перечислены в `[[device]]` и в метке `device`, а `id` называет первую из них.
- Названия оригинальных драйверов и продуктов не используются как имя. Производитель упоминается только как совместимость
  и всегда вместе с `disclaimer`.

## Поля
| поле | обязательно | что это |
|---|---|---|
| `schema` | да | версия формата, сейчас `3` |
| `driver.id`, `driver.family`, `driver.name` | да | идентификатор, семейство и короткое имя |
| `driver.category` | да | `fingerprint`, `touchpad`, `keyboard`, `wifi`, `bluetooth`, `camera`, `audio`, `sensor`, `power`, `gpu` |
| `driver.status` | да | `planned`, `research`, `alpha`, `beta`, `stable` |
| `driver.version`, `driver.license` | да | версия и лицензия (SPDX, сейчас `AGPL-3.0-or-later`) |
| `driver.repository` | да | адрес репозитория |
| `driver.keywords` | нет | слова для поиска, без перевода |
| `driver.default_language` | да | язык, который показывается, если нужного перевода нет |
| `[tags]` | да | метки для фильтров каталога, см. ниже |
| `[text.<язык>]` | да, ≥1 | текст для людей на одном языке, см. ниже |
| `[[device]]` | да, ≥1 | `bus`, `vendor_id`, `product_id` (hex без 0x), `vendor`, `model`, `kind`, `verified_firmware`, `laptops` |
| `[platform.<ос>]` | да | `status`, `components`, `requirements` для `linux`, `redox` |
| `[links]` | нет | пути к README, PROTOCOL, SECURITY, ROADMAP и адреса связанных библиотек |

## Метки (`[tags]`)
Каждая метка — список значений латиницей в нижнем регистре, через дефис. Каталог строит по ним фильтры; одинаковые
значения у разных драйверов означают одно и то же.

| метка | что это | пример |
|---|---|---|
| `vendor` | производитель устройства | `elan`, `mediatek` |
| `class` | класс устройства, как `driver.category` | `fingerprint`, `touchpad` |
| `device` | точные устройства: `<шина>:<vendor_id>:<product_id>` | `usb:04f3:0c4b` |
| `sensor` | устройство изнутри | `image`, `capacitive`, `match-on-host`, `80x80` |
| `bus` | шина | `usb`, `i2c`, `pci` |
| `os` | системы, где драйвер работает | `linux`, `redox` |
| `arch` | архитектуры | `x86_64` |
| `libc` | библиотеки C, с которыми проверен | `glibc`, `musl` |
| `init` | менеджеры служб, которые знает установщик | `systemd`, `openrc`, `runit`, `dinit`, `s6` |
| `integration` | с чем стыкуется | `pam`, `fprintd`, `polkit`, `d-bus`, `tpm2` |
| `desktop` | рабочие столы, на чьи окна настроек рассчитан мост fprintd драйвера | `kde`, `gnome` |
| `laptop` | ноутбуки, где проверен: `<производитель>-<модель>-<тип>` | `lenovo-thinkbook-16-g6-abp-21kk` |
| `language` | языки сообщений драйвера | `ru`, `en` |

## Текст (`[text.<язык>]`)
Весь текст страницы лежит в таблицах по языкам; наборы полей во всех языках одинаковые.

| поле | что это |
|---|---|
| `title` | заголовок страницы, до ~60 символов |
| `summary` | одна фраза: что даёт пользователю |
| `description` | 3–5 предложений: устройство, возможности, важные гарантии |
| `disclaimer` | независимость от производителя |
| `features` | список возможностей |

Поиск на сайте идёт по `vendor_id:product_id`, меткам, `laptops`, `keywords` и `title` всех языков.
